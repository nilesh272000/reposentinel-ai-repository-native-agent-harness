# Recommended workflow

1. Initialize the harness and complete `PROJECT-CONTRACT.md`.
2. Break the objective into small tasks with observable outcomes.
3. Add explicit verification commands to each task.
4. Review and record approval before work begins.
5. Implement with your chosen coding assistant.
6. Run verification and inspect the receipt.
7. Complete only when approval and fresh passing evidence exist.
8. Checkpoint before ending a long session; use `brief` to resume.

Never fabricate approval, reviewer identity or test results. Keep code review and security review independent.
